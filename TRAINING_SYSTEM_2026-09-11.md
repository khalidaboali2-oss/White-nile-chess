# Dowaim Chess Training System — 2026-09-11

## Daily Puzzle
- Deterministic daily selection from a curated set.
- Current set: seven verified-format Mate-in-1 training positions.
- User selects source and destination squares; server records attempts and whether the target solution was found.
- Puzzle rating/streak fields are reserved for the next training iteration; current release reports solved/attempts and keeps streak at 0 until a date-aware streak algorithm is added.
