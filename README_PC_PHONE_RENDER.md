# White Nile Chess Academy — Unified Edition

هذه هي النسخة الموحدة للمشروع، ومناسبة للعمل من الحاسوب والهاتف والنشر كمنصة ويب.

## 1) الحاسوب — تشغيل المنصة محليًا

المجلد المهم: `backend/`

```bash
cd backend
npm install
npm start
```

ثم افتح:
`http://localhost:8080`

يجب أن يظهر موقع الأكاديمية لأن الـBackend يخدم الواجهة الموجودة في `backend/public/`.

## 2) الهاتف — ملفات المشروع

واجهة Android موجودة في `app/`، وملفات الواجهة نفسها موجودة داخل:
`app/src/main/assets/`

هذه ليست APK جاهزة؛ بناء APK يحتاج Android Studio/Gradle وبيئة Android كاملة.

## 3) Render — النشر على الإنترنت

ملف `render.yaml` جاهز كنقطة بداية للنشر. راجع `DEPLOY_TO_RENDER.md` قبل النشر.

بعد النشر اختبر:
- `/health`
- `/ready`
- تسجيل الدخول بحسابين
- مباراة حقيقية عبر WebSocket
- التحديات
- البطولات
- Khalid System
- Team 4x4
- Team Arena
- النتائج والتقييمات

## 4) مهم

هذه النسخة لم تُنشر فعليًا على Render من داخل هذه البيئة، ولم يتم تنفيذ اختبار مباراة حقيقية بين حسابين أو بناء APK فعلي هنا. لذلك لا تُعامل على أنها مثبتة الإنتاج قبل إجراء هذه الاختبارات الخارجية.
